2026-09-20音乐模块大改版

✨ 功能

  • 音乐跨页不断播 + 最小化持续播放：站点壳只换页面内容不销毁播放器；<audio> 永不重建；Media Session（锁屏/媒体键可控）；播放现场持久化，刷新也能接着播。
  • 歌词只换驱动方式：timeupdate + 400ms 定时器双驱动，显示效果完全没变。
  • 点击歌手名弹歌手页：头像 + 简介 + 热门 50 首 + 「▶ 全部播放」（先过滤无版权歌曲）；三接口并行 + 悬停预取。
  • 换页显示记忆：主页与游戏页的显示状态挂 window 缓存，回主页 186ms 出卡片、二次往返 10ms。
  • 历史记录多选删除、清空确认弹窗；弹窗控制键 Windows 风格（− / □ / ✕）。

🐛 Bug 修复

  • site.js boot() 死循环：节点只 push 不摘除 → 先快照再搬移 + try/catch 兜底。
  • data-page 属性丢失：同文件并行编辑互相覆盖，页面脚本不执行（音乐卡片 0 个）→ 教训：同一文件修改必须串行。
  • 弱网下写入空每日缓存：加了 list.length 判断。
  • 「全部播放」文案未复位、换页后模块级缓存重置导致回主页空白、部署脚本对新文件 404 白等 60s。
