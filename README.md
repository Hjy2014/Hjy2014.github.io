# 个人主页 · Personal Portfolio

我的个人作品集网站，纯静态实现（HTML + CSS + JavaScript），无任何构建依赖，托管于 **GitHub Pages**。

## ✨ 特性

- 响应式布局，适配桌面 / 平板 / 手机
- 打字机动画、滚动入场、数字滚动等轻量交互动效
- 移动端汉堡菜单
- 零依赖、零构建，打开即用

## 📂 结构

```
.
├── index.html      # 页面结构
├── css/style.css   # 样式
└── js/main.js      # 交互脚本
```

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可；或启动任意静态服务器：

```bash
python -m http.server 8000
```

## 🌐 线上地址

部署后见 GitHub Pages：`https://<用户名>.github.io/<仓库名>/`
